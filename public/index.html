CLAR extensionUnpacked Chrome extension · current version
Download ZIP ↓
  1. Unzip the download.Keep the extracted folder somewhere permanent. Chrome loads the files from that folder.
  2. Load it in Chrome.Open chrome://extensions, enable Developer mode, click Load unpacked, and select the folder containing manifest.json.
  3. Connect to your CLAR server.Open the extension’s Settings, choose Shared CLAR preview, paste the pairing code below, and save.
  4. Refresh Facebook.Click Analyze on one post. Open its result pill for the compact card; Full analysis opens the detailed side panel.

YOUR PAIRING CODE

This connects the extension to your access on this CLAR server. Keep it private.

Optional automatic scans: In extension Settings, enable Auto-scan to send visible post text for a preliminary reading. Badges are not factual verdicts. Full checks start when you click Analyze. Saved results expire after 24 hours, and Settings lets you clear them.

Future updates: This website and the analysis server update automatically. For changes to the Chrome extension itself, download the new ZIP, replace the extracted files, click Reload in chrome://extensions, then refresh Facebook.
